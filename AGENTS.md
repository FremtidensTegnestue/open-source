# Vejvisning for agenter

- Arbejd i `materialer/` ved opslag i materialedata, beregninger og integration med BIMCraft og SolidCraft. Følg [materialeområdets vejledning](materialer/AGENTS.md). Kør Cargo og eksemplernes relative kommandoer herfra.
- Brug [transformation og genbrug](transformation-og-genbrug/README.md) til spørgsmål om eksisterende bygninger og mulige indgreb. Nye erfaringer, spørgsmål og kilder hører til i debatloggen eller i et oplæg.
- GitHub Actions og den fælles licens ligger i repositoryets rod.
