# Arbejdsark til den første besigtigelse

Et blankt ark til arkitekten, bygherren og dem, der bruger bygningen. Brug det til at formulere valget og bestille de undersøgelser, der kan ændre det. Felterne er vores forslag på baggrund af [kilderne](../kilder/README.md).

## Bygningen og livet i den

| Skriv ned | Spørg på stedet |
| --- | --- |
| Sted, dato, tegningens år og nuværende brug | Stemmer tegningen med det, I ser? Hvem kender tidligere ombygninger og driften? |
| Hvad ønskes ændret, og hvad fungerer allerede? | Tal med beboere og drift hver for sig. Hvornår opleves problemet, hvor, og af hvem? Hvad skal fortsat kunne bruges under arbejdet? |
| Kvaliteter og bindinger | Markér fx en vigtig trappe, fri adgang, dagslys og udsyn, bærende vægge eller facaderytme. Hvad ønsker brugerne bevaret? Hvor vil det have konsekvenser at ændre noget? |
| Anvendelse og indgreb | Skitsér mindst én mulighed, der udnytter rummene, som de står. Skriv, hvad der kræver en opmåling, et myndighedssvar eller en faglig undersøgelse. |

## Ét kort per del eller ensartet parti

| Felt | Hvad skal kunne spores? |
| --- | --- |
| Identitet og oprindelse | Eget ID, donorbygning, etage/rum, tegning, foto og registrant. Giv partier med forskellig historik egne ID'er. |
| Mål og mængde | Angiv måleenhed og målemetode. Hold det registrerede antal adskilt fra antal, som efter sortering er egnede, og antal, som til sidst er indbygget. |
| Stand og funktion | Synlige skader, tidligere eksponering, vedligehold, mulig reparation og forslag til næste brug. Angiv hvordan en ukendt egenskab kan undersøges. |
| Dokumentation | Prøver, vurderinger, rapport og ansvarlig. Hvilken del og hvilke betingelser gælder hvert resultat for? Er der et uafklaret spørgsmål om problematiske stoffer eller teknisk egnethed? |
| Vejen til aftageren | Mulighed for skånsom adskillelse, forventet spild, tilgængelig dato, oplagring, transport, modtager og tidspunkt for kontrol. |
| Ny løsning | Vis hvad der bliver siddende, hvad der flyttes, og hvad der må købes nyt. Beskriv, hvordan delen kan repareres eller udskiftes senere. |

## Sammenlign og følg op

Skriv alternativerne på samme linje som det behov, de løser. For hvert alternativ angives funktion, brugere, periode, mængder, enheder, opvarmet areal, vedligehold og de mest usikre antagelser. Vis både anlæg og forventet drift. Skriv udtrykkeligt, om en post er med, endnu ukendt eller vurderet uden betydning. En tom celle er ingen måling af nul.

Afslut mødet med at skrive, hvilken oplysning der kan vende valget, hvem der finder den og hvornår. Efter udførelse tilføjes faktisk indbygget antal, udfald ved sortering, beboernes erfaringer og eventuelle målinger med periode og enhed. Registrér, hvis brug eller areal ændrede sig mellem målinger.
