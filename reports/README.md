# Projektrapporter

[Lisbjerg Bakke](lisbjerg-bakke/README.md) er en afprøvning på de originale ARK-/KON-modeller og 132 tegningssider. Rapporten beskriver, hvad der kan beregnes, og hvilke oplysninger der mangler. Der dannes ikke en samlet bygnings-LCA.

[Det lille integrerede eksempel](../examples/integrated-workflow/README.md) er det anbefalede første forløb, hvis du vil se en komplet kontrolleret kæde med modelændring.
