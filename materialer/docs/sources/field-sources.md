# Materialedata fra laboratorier, genbrugsprojekter og markedsstatistik

En arkitekt kan slå et bestemt nedtaget element op, læse et materiales målte lydabsorption ved forskellige frekvenser eller undersøge, hvilke monteringsforhold der hører til en gulvbelægnings brandklasse. Hvert svar identificerer emnet, originalfilen og den række, celle eller side, som oplysningen kommer fra.

## Prøv det fra mappen `materialer`

```sh
ft-materials build --supplement data/supplements/field-sources --require-originals
ft-materials facts field-sources:material:recreate-BR_FI_STTO_KYTU_1982C_Pa-1305 --field reuse_evidence
ft-materials facts field-sources:material:wood-flooring-1 --field reaction_to_fire
ft-materials facts field-sources:material:nist-633a --field chemical_constituent
ft-materials coverage --dataset field-sources --field sound_absorption_coefficient
```

Bygkommandoen vælger dette supplement sammen med Parquet-grundlaget. For at anvende alle offentlige supplementer kan du følge [projektets byggevejledning](../RUST.md). Hele kurven ligger i feltets værdi med `x_values`, `y_values`, `x_unit` og `x_property`. Læs alle værdier ved at bladre med `--limit` og `--offset`.

## Genopbygning og kontrol

`ft-materials collect-field-sources` kontrollerer hver original mod [arkivregistrets](../../data/supplements/field-sources/archive.json) SHA-256 og gendanner de strukturerede data lokalt i Rust. De redaktionelle aflæsninger fra PDF-tabeller kan kontrolleres direkte i [transskriptionen](../../data/supplements/field-sources/transcription.json). Den nævner tabelrække, side og betingelser for hver oplysning. Originalfilerne følger med repositoryet og kan hentes igen på den enkelte kildes URL.

Alle felter udgives i den komprimerede `facts.jsonl.gz`. Skalarer og kurver er desuden tilgængelige i `observations.jsonl.gz`, så de eksisterende egenskabsopslag kan benytte dem. De to repræsentationer beskriver de samme målinger. Antallet af emner, felter og observationer kan efterprøves i [udgavens optælling](../../data/supplements/field-sources/summary.json).
